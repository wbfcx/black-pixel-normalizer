# 黑色像素修正工具

> 杂货铺 #002 附属项目 A

一个简单的图片处理小工具。

用于将图片中接近黑色的像素统一修正为纯黑色，并保留原有透明度。

## 功能

- 支持拖入图片
- 支持手动选择图片
- 支持 PNG、JPG、JPEG、BMP、WebP
- 检测接近纯黑的像素
- 将近黑色像素统一修正为纯黑色
- 保留原有透明度
- 自动输出处理后的 PNG 图片
- 不覆盖原始图片

## 处理规则

当前默认阈值：

```text
RGB 三个通道都小于或等于 10
```

满足条件的像素会被转换为：

```text
R = 0
G = 0
B = 0
```

透明度 Alpha 保持不变。

例如：

```text
(8, 7, 9, 255)
```

会被转换为：

```text
(0, 0, 0, 255)
```

## 输出文件

处理完成后，会在原图片所在目录生成：

```text
原文件名_blackfix.png
```

例如：

```text
test.png
```

处理后生成：

```text
test_blackfix.png
```


## 运行环境

需要安装 Python，以及以下依赖：

```text
PyQt6
Pillow
```

也可以在项目目录执行：

```bash
pip install -r requirements.txt
```

然后运行：

```bash
python 背景归一.py
```
